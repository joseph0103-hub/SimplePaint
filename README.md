# (C# 코딩) SimplePaint

## 개요
- C# 프로그래밍 학습
- 1줄 소개: 선, 사각형, 원을 선택하여 그릴 수 있는 간단한 그림판 프로그램
- 사용한 플랫폼: C#, .NET Windows Forms, Visual Studio 2026, GitHub
- 사용한 컨트롤: Label, GroupBox, Button, ComboBox, TrackBar, PictureBox
- 사용한 기술과 구현한 기능: UI 배치, 도형 선택, 색상 선택, 선 굵기 선택, 마우스 드래그 그리기, 파일 저장, 외부 이미지 열기
